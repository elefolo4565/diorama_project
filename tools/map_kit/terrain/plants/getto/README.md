# ゲットウ — Alpinia zerumbet

## 制作前に決めた株の形

太い幹も木の枝もない。直径 2〜3cm の緑の偽茎が根元から何十本も立ち、上の方ほど外へ弓なりに開く、花瓶〜噴水形のやぶ。根元は狭く、上部は幅 1〜3m。長い楕円の葉を各茎の両側へ互い違いに付け、葉先を少し下げる。海風による一方向の強い傾きは付けない。

- A: 2.8m、22 本の偽茎が立つ古い大株。上部を広く開く。
- B: 2.3m、18 本。帯状の群落の端として一方向へ少し広がる。
- C: 1.7m、14 本。新しい細い株で、葉の間の隙間を残す。

## 共通メモへの対応

`plants/notes/getto.md` に従い、葉は約 40〜70cm、幅約 8〜15cm のなめらかな長楕円。つやのある緑、中央の葉脈と細い側脈を描く。茎に枝は作らない。夏の `_Hana` にだけ、茎の先から約 20〜30cm の白・ピンク・黄色の花房を垂らす。白い貝殻状のつぼみ、黄色に赤い筋の唇弁を自作 PNG に描く。

季節はメモの指定どおり 2 つ。葉だけの基本形は春・秋・冬 (13)、花の形は夏 (2)。同じ株の形を複製し、花房だけを加除する。秋の実は葉だけという季節指定に合わせて省く。

九州南部〜沖縄の道ばた・集落の周り・明るい林床を表すため、regions=kyushu, okinawa、habitat=farm, understory。大きいやぶが並びすぎないよう share=A .045、B .035、C .025。

外部の写真・画像・モデルは使用しない。形・葉・花・茎の PNG はすべて自作する。

## プレビューでの修正

1. 初稿の正面・横では茎の開きと葉先がそろったため、茎ごとの開きに差を付け、葉先をさらに下げた。B は群落の端として片側への張り出しを残した。
2. 二稿では水平の葉が正面から細く見えたため、葉を少しねじり、幅を広げ、葉の付け根から先への反りを強めた。花房の付け根を茎先に近づけた。最終の正面・横・真上と Blender の通常形・夏形を確認した。

全個体の habitat は farm, understory。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kyushu, okinawa。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py getto` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
