# アカメガシワ (Mallotus japonicus)

## 制作前の樹形

`plants/notes/akamegashiwa.md` と AGENTS.md の「季節の形のきまり」を基準にする。写真や `*opus.py` は開かず、形と画像を自作する。

- 低い所で分かれる 1〜3 本の幹。裸の幹は全高の約 15〜20%。灰白色の枝を水平〜斜め上へ広げる。
- 横に広い傘形の明るい樹冠。枝先ごとの葉の層の間から空が見える。丸い密な葉の球で包まない。
- 主枝・中枝・小枝・枝先の細枝と 4 段階に細くし、冬にも枝先が読める骨格にする。
- 10〜20cm の広い卵形〜ひし形の葉。一部は浅い三裂にし、10〜20cm の赤い葉柄の先でほぼ水平に開く。
- A は 7.4m の単幹の傘形、B は 5.8m の 3 本立ちで片側に張る畑のふちの木、C は 5.2m の 2 本立ちの若木。幹数・主枝数・幅を変え、単なる縮小にしない。
- B は明るい側へ少し傾けるが、海岸の風衝形にはしない。

## 季節の形

各個体にちょうど 4 形を作る。夏の基本形 = 2、春 `_Haru` = 1、秋 `_Aki` = 4、冬 `_Fuyu` = 8。派生形は全て基本形を `place_with` に指定する。
枝は一度だけ生成し、同じ頂点の骨格を全季節へコピーする。春は赤〜赤紫、夏は明るい緑、秋は黄葉とし、葉の形・UV・透過は共通にする。
冬は同じ骨格から葉と赤い葉柄を完全に除く。透明な葉板を残す方法は使わず、灰白色の幹と枝だけを納品する。
検査プレビューの右端は全ての葉画像の一覧で、左側の各行の季節とは対応しない。冬の GLB に葉のマテリアルや板が無いことはファイルの中身でも検証する。
夏の花穂は今回の 4 形には追加せず、メモ指定の季節数を守る。春の新芽は同じ葉面に新芽色を描く近似とする。

## 配置

道ばた・畑のふち・林縁の先駆樹を表す `farm`。A/B/C の割合は 3%・2.5%・2% (合計 7.5%)。同じ個体の季節形を重ねて加算しない。
地方は北海道を除く 9 地方。[森林総合研究所・九州支所](https://www.ffpri.go.jp/kys/business/jumokuen/jumoku/zukan/akamegasiwa.html) の分布の文章を確認した。東北では北部を除く分布を地方単位で近似する。写真は閲覧・利用していない。

## 画像確認後の改稿

1. 初稿は葉が水平な薄い輪に寄り、枝の露出が多すぎた。幅を抑えて葉のある枝先を内外へ分散し、葉の層を高さの異なる段に分けた。葉の向きも傾きとねじれを加え、正面・横から大きな葉が読めるようにした。
2. 第 2 稿でも葉が少なすぎたため、隠れる葉柄の端面を省いて葉へ三角形を振り替え、枝先の葉を 5 枚から 8 枚へ増やした。葉のねじれも増やした。冬に見える細枝は少し太くし、先まで段階的に細くなる骨格を保った。
3. Blender の斜視でも葉が薄く見えたため、枝先へ実寸約 15〜20cm の葉 3 枚と長い赤い葉柄を描いた小さな葉群の板を追加した。冬にはこの板も完全に除く。葉の段の間には空が見える隙間を残した。

`regions`: kyushu, okinawa, shikoku, chugoku, kansai, chubu, kanto, tohoku, hokuriku。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py akamegashiwa` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
