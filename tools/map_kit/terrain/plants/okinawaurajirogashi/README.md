# オキナワウラジロガシ — Quercus miyagii

## 制作前に決めた樹形

まっすぐで太い単幹が高くまで伸び、樹高の約 42% から太枝を斜め上〜横へ広げる。裸の幹は下の約 40%。分岐の高さまで直径 0.6〜1m 程度を保ち、6・5・4 本の太枝の先に分かれた樹冠のかたまりを付ける。横に広く、上端がやや平らな樹冠とし、周囲の森より高く出る。根元に 3〜5 枚の板根が放射状に張り出す。林内の個体なので海風で強く曲げない。

- A: 23m、直径約 1m。幅約 14m の大きな樹冠、板根 5 枚 (最高約 1.3m)。
- B: 19m、直径約 80cm。わずかに傾き、片側へ広い樹冠。板根 4 枚。
- C: 16m、直径約 60cm。細長い若い高木で、幅約 10m の樹冠。板根 3 枚。

## 共通メモへの対応

基準は `plants/notes/okinawaurajirogashi.md` と FIXES.md。葉は 8〜15cm の細長い楕円で、上半分に浅い鋸歯を付ける。表はつやのある濃緑。白っぽい裏葉を緑のアトラスにも混ぜ、同じ透過輪郭の裏葉用 PNG も自作して外側に点在させる。灰褐色で比較的なめらかな樹皮に薄い割れ目。花・どんぐりは遠目に目立たないので省略し、指定どおり一年中共通の 1 形 (seasons=15)。

沖縄本島北部・石垣・西表の山の林と谷沿いなので regions=okinawa、habitat=forest。森の上に高く出る大木が密集しすぎないよう share は A=.035、B=.025、C=.020。

外部の写真・画像・モデルを使わず、葉・樹皮・形を自作する。

## プレビューでの修正

1. 初稿の正面・横と Blender 画像では輪郭と板根がそろいすぎたため、葉房の張り出し、板根の長さ・高さ・方位をばらした。高くまっすぐ伸びる単幹と、上部で枝を広げる形はメモどおり残した。
2. 板根の上辺が直線的だったため、中間の頂点を増やして幹から地面へ曲線状に下がる形にした。根の先ほど薄くし、幹から出る上端も高くした。樹冠の下端は房の板数を減らし、房ごとに高低差を付けた。

## FIXES.md の樹形の修正

2026-10-17、修正案 1: 幹の太さを高い分岐まで保ち、太枝の分岐を露出させた。各太枝に対応する複数の樹冠へ組み直し、上端をやや平らにして、白っぽい裏葉を表面に点在させた。

修正案 2: 正面・横・真上を見て、外側の樹冠の中心を広げ、各かたまりの半径を小さくして枝ごとの輪郭を分けた。下端の房を疎にし、高さをばらした。裏葉の房の間隔も 9 房ごとから 6 房ごとに増やした。最終の check.py と Blender の A/B/C を確認した。

全個体の habitat は forest。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: okinawa。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。
