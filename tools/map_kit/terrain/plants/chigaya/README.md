# チガヤ — Imperata cylindrica

## 制作前に決めた草地の形

地下茎で広がる細い葉が地面から密に立ち、背の低い一面の草地になる。木の幹や枝、大きな噴水形の株は作らない。葉は直立〜少し斜めで、先だけが軽く曲がる。根元は列に並べず、面に均等に散らす。葉先の高さに小さい差を付け、外縁をばらす。

- A: 春の穂先で約 75cm、葉は約 30〜50cm。密な草地の区画。
- B: 約 62cm。あぜに広がる横長の区画。葉の高さを低めにする。
- C: 約 48cm。新しく広がった小さい草地の端で、葉の密度と高さを少し下げる。

## 共通メモへの対応

`plants/notes/chigaya.md` に従い、20〜50cm の細い線形の葉、幅約 0.5〜1cmを作る。夏は明るい〜やや青みのある緑。秋冬の PNG は下部を灰褐〜淡い茶色、葉先を赤褐色にする。

季節は指定の 3 つ。夏の基本 (2)、春の白い綿毛の穂 `_Haru` (1)、秋冬の枯れ色 `_Fuyu` (12)。葉の位置・形はすべて同じで色だけを替え、春だけ葉の上に 10〜20cm の銀白色の円柱形の穂を多く付ける。花茎も春だけ表示し、夏に裸の花茎を残さない。

全国の草原・あぜ・道ばた・堤防に生えるため regions は沖縄〜北海道の全 10 地方、habitat=grassland, farm。低い草地として share=A .08、B .06、C .04。現在の受け口は草原全体への連続した被覆率を直接指定できず、木を入れ替える割合で区画を置く。

外部の写真・画像・モデルは使わず、葉・穂・葉鞘の形と絵を自作する。

## プレビューでの修正

1. 初稿の葉が直立しすぎたため、わずかに傾く葉を増やした。穂の上下向きを正し、綿毛の縁を増やした。秋冬の赤褐色の先と灰褐色の根元は、境目をなめらかにした。季節ごとの実寸を height_m に記録した。
2. 二稿のプレビューと Blender を見て、葉先の反りと高さに差を付けた。春の白い穂を 25% 増やし、葉の上が銀白色にかすむようにした。葉の骨格は全季節で同じものを複製した。

`regions`: kyushu, okinawa, shikoku, chugoku, kansai, chubu, kanto, tohoku, hokuriku, hokkaido。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py chigaya` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
