# スダジイ (沖縄のイタジイ) — Castanopsis sieboldii

## 制作前に決めた樹形

太い短い幹が低い所で 2〜3 本に分かれ、主枝を斜め上から横へ大きく広げる。裸の幹は下の約 15〜25%。半球形の樹冠の表面に大小の丸い房が集まり、上から見るとブロッコリーのように見える。幅は高さの約 1〜1.5 倍。根元を張り、古い幹は少しねじる。森の個体は強く風で傾けず、林縁の B は片側に開く。

- A: 16m の老木、太さ約 80cm、3 本に分岐。横広い房の集まった樹冠と張り根。
- B: 12m、太さ約 60cm、2 本に分岐。林縁で片側へ広がる枝と非対称な樹冠。
- C: 10m、太さ約 50cm、3 本の上向きの枝。樹冠は狭く、成木の縮小にはしない。

## 共通メモへの対応

基準は `plants/notes/sudajii.md`。5〜10cm の長い楕円で先のとがる濃緑の葉を、互生する 2 列の小枝として自作する。少数の金褐色の裏葉を混ぜる。古木の暗灰褐色の樹皮には深い縦割れを描く。通常形は seasons=14 (夏・秋・冬)、春の `_Hana` は seasons=1。春は細いクリーム色〜淡黄色の花穂を表面へ多数置いて、樹冠全体が黄色みを帯びるようにする。2 形の幹・枝・葉の頂点は同一にする。

やんばる・西表の山の林の主要な木なので habitat=forest。share は A=.10、B=.06、C=.04 とし、大木・林縁木・若木を混ぜる。[森林総合研究所の分布説明](https://www.ffpri.go.jp/kys/business/jumokuen/jumoku/zukan/sudajii.html) と特徴メモを合わせ、北海道以外の暖かい地域を regions にする。地方単位なので、東北などでは自生域の北限より北にも選ばれうる。

写真は見ず、形と PNG は自作する。外部の画像・モデル・アセットは使用しない。

## プレビューでの修正

1. 初稿の正面・横と Blender 画像では葉が透け、樹冠が高くまとまりすぎていた。葉の長さを変えずに小枝のアトラスを密にし、房を低い位置へ広げた。C の幅もメモの範囲へ広げ、花穂は数を倍にして表面の外へ出した。
2. 二稿では葉の塊がばらばらで内部に板を使いすぎていたため、葉の板を樹冠の表面へ配り直した。房の数を増やし、1 房の板数を減らして、総数をほぼ保ったまま連続した樹冠にした。輪郭には丸い房の凹凸を付け、下側の房の高さと密度を散らした。花穂の位置と板の向きもばらし、真上にも春の色が見えるようにした。
3. 三稿の輪郭はまだ均一な楕円に近かったため、丸い房の張り出しと上下差を強め、ブロッコリー状の大きな凹凸を付けた。

全個体の habitat は forest。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kyushu, okinawa, shikoku, chugoku, kansai, chubu, kanto, tohoku, hokuriku。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py sudajii` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
