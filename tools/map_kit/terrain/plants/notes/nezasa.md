# ネザサ (Pleioblastus argenteostriatus f. glaber)
- 形: 地下茎で広がり、すき間なく密なやぶを作るササ。高さ 1〜2m (刈られるあぜでは 0.3〜0.8m)。細い稈 (太さ 3〜8mm) が真っすぐ立ち、上の方で枝を出して葉が茂る。やぶの上面は葉の重みで外へ弓なりに垂れる
- 葉: 10〜25cm の細長い披針形、先がとがる。薄く明るい緑〜黄緑、つやは弱い。枝先に 3〜9 枚ずつ手のひらのように広がる
- 群れ: 1 株ではなく帯状・面状に続く。下の方は枯れた茶色の葉と稈が混じり、上ほど緑が濃い。冬は葉の縁が白く枯れて色が淡くなる
- 生える所: 林のふち・道沿い・田のあぜ・土手 (understory, farm)
- 季節の形: 春・夏・秋 (1+2+4) = 明るい緑 / 冬 (8) = 葉の縁が白く枯れて全体に淡い色
