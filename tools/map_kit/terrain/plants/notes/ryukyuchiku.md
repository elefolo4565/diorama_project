# リュウキュウチク (Pleioblastus linearis)
- 形: 細いササ〜タケの仲間。高さ 2〜5m。細い稈 (太さ 1〜2cm) が密に立ち並び、背の高いやぶを作る (向こうが見えないほど)。稈はまっすぐ立って先が少しだけ曲がる。上の半分に枝が出て葉が付き、下の方は葉の落ちた稈が茶色〜灰色に並ぶ
- 稈: 緑〜黄緑で、古いものは灰褐色〜茶色。節ごとに古い鞘 (茶色) が付いたまま残る
- 葉: 長さ 10〜25cm、幅 0.5〜1cm のとても細長い線形 (ふつうのササよりずっと細い)。濃い緑でつやは弱い。枝先に 5〜10 枚が手のひらのように集まり、斜め下へ垂れる。やぶの表面は細い葉の房が重なってざらっとした質感
- 季節の形: 1 つ (一年中ほぼ同じ)
- 生える所: 尾根・山の斜面の荒れ地・伐採跡・道ばた (grassland, ridge)。九州南部 (甑島・大隅) 〜沖縄
