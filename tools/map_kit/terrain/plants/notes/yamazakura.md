# ヤマザクラ (Cerasus jamasakura, iNaturalist では Prunus jamasakura)
- 樹形: 落葉高木。樹高 15〜25m。幹は 1 本で高い所まで伸び、上の方で太い枝が斜め上へ分かれる。樹冠は丸い〜扇形で、すき間が多い。山では常緑の林や植林の中に 1 本ずつ点々と混じり、春だけ白〜淡いピンクの塊として浮かび上がる (ソメイヨシノのような横に広がる並木の形ではない)
- 幹: 暗い紫褐色〜灰褐色でつやがあり、横向きの細長い皮目 (横じま) が目立つ。古い木は表面が荒れて苔が付く。太さ 30〜60cm
- 葉: 8〜12cm の卵形〜楕円、先が細くとがり、ふちに細かいぎざぎざ。夏は濃い緑
- 花・実: 3 月下旬〜4 月、白〜淡いピンクの 5 弁の花 (直径 3cm) が、赤茶色〜赤紫の新芽 (若葉) と同時に開く。樹冠は白い花と赤茶色の若葉が混じった色に見える。初夏に黒紫色の小さな実
- 季節: 10〜11 月に黄〜オレンジ〜赤に紅葉。冬は葉がなく、横じまのある暗い枝だけ
- 季節の形: 4 つ。春 = 白〜淡いピンクの花と赤茶色の若葉 (`_Hana`)、夏 = 緑 (基本の形)、秋 = 黄〜オレンジ〜赤の紅葉 (`_Aki`)、冬 = 葉を落とした暗い紫褐色の枝だけ (`_Fuyu`)
- 生える所: 山の林・尾根に点々と (forest, ridge)
