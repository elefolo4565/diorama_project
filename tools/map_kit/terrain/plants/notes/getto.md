# ゲットウ (Alpinia zerumbet)
- 形: ショウガの仲間の大きな多年草。高さ 1.5〜3m。根元から細い茎 (偽茎、太さ 2〜3cm) が何十本も束になって立ち、上の方で斜め外へ弓なりに開く。株は幅 1〜3m の、上が広がった花瓶〜噴水形のやぶ。隣の株とつながって道ばたに帯状に続く
- 茎: 緑色でまっすぐ、葉の付け根の鞘が重なって包む。枝はない
- 葉: 長さ 40〜70cm、幅 8〜15cm の長い楕円 (先がとがる)。ふちはなめらかで、明るい〜ふつうの緑、強いつや。茎の両側に 2 列に互い違いに付き、水平〜斜めに張り出して先が少し垂れる
- 花・実: 5〜6 月に茎の先から長さ 20〜30cm の花房が垂れ下がる。つぼみは白く先がピンク、開くと黄色に赤い筋の唇弁 (貝殻のような形)。秋に 2cm ほどの実が房になり、緑 → 黄 → オレンジ〜赤に熟して垂れる
- 季節の形: 2 つ。秋〜春 = 葉だけ (基本の形)、初夏 = 白とピンクの花房が垂れる (`_Hana`)
- 生える所: 道ばた・林のふち・集落のまわり (farm)、明るい林の足もと (understory)。九州南部〜沖縄・八重山
