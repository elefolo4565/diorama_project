# クサトベラ (Scaevola taccada)
- 樹形: 常緑の低木。高さ 1〜3m。根元から太い枝が何本も斜め〜横に伸び、枝分かれをくり返して、上が丸くそろったこんもりした塊になる (幅は高さの 2〜3 倍)。砂浜の奥では隣の株とつながり、腰〜背の高さの緑の帯が海岸線に沿って続く
- 幹: 灰褐色で太さ 3〜10cm、くねって斜めにはう。葉の落ちた跡が節になる。外からはほとんど見えない
- 葉: 10〜20cm のへら形 (先が丸く根元が細い)。厚く多肉質で、明るい黄緑〜あざやかな緑、強いつや。枝先に 10〜20 枚がらせん状に集まってロゼットのように開き、枝先ごとの葉の房が樹冠の表面を埋める
- 花・実: 白い花 (2cm) は花びらが片側だけに扇のように開く (半分に切れた形)。葉の房の中心近くに数輪ずつ。ほぼ一年中だが遠目には目立たない。白い丸い実 (1cm)
- 季節の形: 1 つ (一年中ほぼ同じ)
- 生える所: 砂浜の奥・海岸の岩場 (coast)。グンバイヒルガオの草地とアダン・モンパノキのやぶの間。奄美〜沖縄・八重山、小笠原
