# テリハボク (Calophyllum inophyllum)
- 樹形: 常緑高木。樹高 8〜15m (風の強い岸では 3〜6m)。幹は太く短めで、低い所から太い枝が斜め上〜横へ広がる。樹冠は丸い〜横に広い卵形で密 (幅は高さの 1〜1.3 倍)。海岸の防潮林では列になって並び、潮風側の樹冠は低く削られた形になる
- 幹: 灰色〜灰褐色、縦に浅い割れ目と小さなはがれ。樹高 10m で太さ 30〜60cm。根元が少し張る
- 葉: 10〜18cm の楕円、先は丸いかわずかにへこむ。厚い革質で、表は濃い緑で強いつや (名前の由来)。細い平行な葉脈がたくさん走る。枝に向かい合って付き、枝先に集まる
- 花・実: 初夏に白い 2〜3cm の花の房 (遠目には目立たない)。夏〜秋に 3〜4cm の丸い実 (緑 → 茶色)
- 季節の形: 1 つ (一年中ほぼ同じ)
- 生える所: 海岸の防潮林・砂浜の奥 (coast)、集落の防風林。沖縄・八重山・小笠原
