# アカギ (Bischofia javanica)
- 樹形: 常緑高木 (半落葉)。樹高 15〜25m。太い幹が 3〜6m の高さで何本もの太い枝に分かれ、枝は斜め上〜横へ大きく張る。樹冠は横に広い丸形〜不規則なドーム形 (幅は高さの 1〜1.5 倍) で、葉の塊の間にすき間がある。大木は幹がこぶだらけでねじれる
- 幹: 赤褐色〜紫がかった褐色 (名前の由来)。古い樹皮は薄い片になってはがれ、はがれた跡がまだらに明るい。樹高 15m で太さ 50cm〜1m、根元が張る
- 葉: 小葉 3 枚の複葉 (手のひらに 3 つ)。小葉は 8〜15cm の卵形で先がとがり、ふちに細かいぎざぎざ。明るい〜ふつうの緑で強いつや。長い葉柄で枝先に集まる
- 花・実: 春に葉の付け根から黄緑色の小さな花の房が垂れる。秋〜冬に 1cm ほどの丸い実の房 (茶色 → 黒っぽい)。遠目には目立たない
- 季節の形: 1 つ (一年中ほぼ同じ。春に古い葉が一部黄色くなって落ち、新しい葉で樹冠が明るい黄緑になる程度)
- 生える所: 低地の林・谷沿い (forest)、集落の大木・街路樹 (farm)。奄美〜沖縄・八重山、小笠原 (小笠原では森に広がって困っている)
