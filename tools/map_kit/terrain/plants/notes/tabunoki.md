# タブノキ (Machilus thunbergii)
- 樹形: 常緑高木。樹高 15〜20m。幹は太く、地上 3〜5m で太い枝に分かれて斜め上へ広がる。樹冠は丸く大きなドーム形 (幅は高さの 1〜1.3 倍) で、表面は大きな葉の塊がこんもりと重なり、濃い緑で暗く重い感じ (クスノキより色が濃い)。海に近い林では樹冠どうしが寄り合って続く
- 幹: 灰褐色〜褐色で比較的なめらか、小さな皮目 (ぶつぶつ) がある。太さ 40cm〜1m、古い木は根元が張る
- 葉: 8〜15cm の倒卵形〜長い楕円 (先の方が幅広い)、厚い革質。表は濃い緑で強いつや、裏は白っぽい。枝先に集まって輪のように付く (枝先ごとに葉の束)
- 花・実: 4〜5 月、新芽と一緒に黄緑色の小さな花の房。7 月に黒紫色の丸い実 (1cm) が赤い柄の先に付く (赤い柄が目立つ)
- 季節: 3〜4 月に枝先の大きな冬芽が開き、赤〜赤茶色の新芽の束が樹冠の表面に立つ。初夏は新しい葉が明るい黄緑で古い葉の濃い緑と混じる
- 季節の形: 2 つ。夏・秋・冬 = 濃い緑 (基本の形)、春 = 枝先に赤〜赤茶色の新芽の束 (`_Haru`)
- 生える所: 海に近い林・社寺林・海岸の斜面 (coast, forest)
