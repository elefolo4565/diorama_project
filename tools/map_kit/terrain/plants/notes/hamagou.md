# ハマゴウ (Vitex rotundifolia)
- 樹形: 砂浜をはう落葉の低木。高さ 0.3〜0.7m。茎が砂の上を数 m はって伸び、ところどころから短い枝が立ち上がる。直径 2〜5m の平たいマット (じゅうたん) 状の群れになり、砂浜の奥〜海岸の岩の間に広がる。群れの表面は小さな丸い葉でびっしり覆われ、低く盛り上がる
- 幹: はう茎は灰褐色〜白っぽい灰色の木質で、太さ 1〜2cm。砂に半分埋まる
- 葉: 3〜6cm の丸い卵形、ふちはなめらか。2 枚ずつ向かい合って付く。表は灰緑色、裏は細かい毛で銀白色 (群れ全体が白っぽい灰緑色に見える)。厚く、香りが強い
- 花・実: 7〜9 月、枝先に青紫色の唇形の小さな花 (1.5cm) が穂になって立ち、群れの表面に点々と紫が散る。秋に茶色〜灰色の丸い実 (5mm) の房
- 季節: 冬は葉の多くが黄色くなって落ち、灰色の茎が目立つまばらな群れになる (暖かい所では一部の葉が残る)
- 季節の形: 3 つ。春・夏 = 灰緑色のマット (基本の形)、夏の終わり = 青紫の花の穂が点々と (`_Hana`)、冬 = 葉が少なく黄〜灰色の茎が目立つ (`_Fuyu`)
- 生える所: 砂浜の奥・海岸の岩場 (coast)
