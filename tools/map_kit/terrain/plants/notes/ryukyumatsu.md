# リュウキュウマツ (Pinus luchuensis)
- 樹形: 単幹の常緑針葉樹。樹高 10〜20m (尾根・海岸の崖では 5〜8m)。若い木は円すい形、育つと上の方で枝を横に大きく張り、頂が平らな笠形〜傘形の樹冠になる。林の中では幹の下半分に枝がなく、樹冠は上 1/3 だけ。崖や海岸では幹が斜めに傾き、枝が風下へ流れる
- 幹: 赤褐色〜灰褐色。下の方は黒っぽく、厚い亀甲状の割れ目。上の方と太い枝は赤みが強い。樹高 15m で太さ 30〜50cm。幹は少しくねる
- 葉: 2 本ずつ束になった針状の葉 (長さ 15〜20cm、クロマツより細くやわらかい)。明るめの緑〜黄緑。枝先に房のように集まり、房のすき間から枝と空が見える
- 花・実: 春に枝先に紫褐色の雄花の穂。球果は 5cm ほどの卵形で、茶色く枝に残る (遠目には目立たない)
- 季節の形: 1 つ (一年中ほぼ同じ)
- 生える所: 沖縄の山の尾根・中腹の林 (ridge, forest)、海岸の崖の上。やんばるの森では広葉樹の林から頭を出す
