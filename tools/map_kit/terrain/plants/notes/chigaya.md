# チガヤ (Imperata cylindrica)
- 形: 草原・あぜをびっしり覆うイネ科の多年草。高さ 30〜80cm。地下茎で広がり、細い葉がまっすぐ立ちそろった、密で背の低い草地 (しま模様にならない一面の緑) を作る
- 葉: 長さ 20〜50cm、幅 0.5〜1cm の細い線形。まっすぐ〜少し斜めに立ち、先は細くとがる。明るい緑〜少し青みのある緑。秋には先から赤〜赤褐色に色づき、冬は枯れて淡い茶色〜灰色の草地になる
- 花 (穂): 春〜初夏 (沖縄 3〜4 月、九州以北 5〜6 月) に、葉より上へ 10〜20cm の細い円柱形の穂。出たては赤褐色〜紫、すぐ白い綿毛に覆われて銀白色のふさふさになる。たくさんの穂が一面にそろい、草地が白くかすむ
- 季節の形: 3 つ。夏 = 緑の葉だけ (基本の形)、春〜初夏 = 白い綿毛の穂が一面に (`_Haru`)、秋〜冬 = 赤〜茶色に色づき枯れた草地 (`_Fuyu`)
- 生える所: 草原・あぜ・道ばた・堤防・海岸近くの草地 (grassland, farm)。全国 (沖縄〜北海道南部)
