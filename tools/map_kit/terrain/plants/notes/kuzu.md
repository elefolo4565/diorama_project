# クズ (Pueraria montana var. lobata)
- 樹形: 大型のつる (多年草〜半低木)。地面・土手・低木・林のふちの木をすき間なく覆い、高さ 1〜10m の大きな緑の塊・カーテンになる。下にある木や電柱の形がそのまま緑の山・壁になったように見える (ほかの植物が見えなくなる)。表面は大きな葉が重なって波打ち、葉の裏の白っぽい面がところどころ見える
- 茎: 太い茎は茶色の木質で太さ 1〜3cm、若いつるは茶色の毛が生える。冬は枯れた茶色のつるが網のように残る
- 葉: 3 枚の小葉からなる大きな葉 (小葉 1 枚 10〜18cm のひし形〜卵形、ときに浅く 2〜3 つに裂ける)。表は緑〜黄緑、裏は白っぽい灰緑色。長い葉柄で、葉が立ち上がって表面をうろこのように覆う
- 花・実: 8〜9 月、葉の付け根から赤紫〜ピンクの小さな蝶形の花が 10〜20cm の穂になって立つ (葉の間からのぞく程度)。秋に毛のある茶色の平たい豆のさや
- 季節: 11 月に黄色〜くすんだ黄緑になり、霜で枯れる。冬は葉がなく、茶色の枯れたつると枯れ葉が覆ったまま残る (下の木が茶色の網に包まれる)
- 季節の形: 4 つ。春 = 小さな若い葉がまばら (`_Haru`)、夏 = 大きな緑の塊 (基本の形)、秋 = 黄色〜くすんだ黄緑 (`_Aki`)、冬 = 茶色の枯れたつると枯れ葉 (`_Fuyu`)
- 生える所: 林のふち・道路の土手・空き地・河原・畑のふち (farm, grassland)
