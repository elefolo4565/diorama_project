# ヤマツツジ (Rhododendron kaempferi)
- 樹形: 半落葉の低木。高さ 1〜3m (日当たりのよい草原・尾根では 4m 近くの大株も)。根元から細い枝がたくさん出て、斜め上へ広がり、枝先が何度も分かれる。株は横に広い丸い〜不規則な形で、林の中ではまばら、林のふち・尾根の日なたでは葉と花が密な塊になる
- 幹: 灰褐色の細い枝 (太さ 1〜5cm)。くねりながら分かれる
- 葉: 春の葉は 3〜5cm の楕円で、枝先に輪のように集まる。明るい緑〜緑、つやは弱く、細かい毛がある。夏に出る葉は小さく (1〜2cm) 冬も残る
- 花・実: 4〜5 月、枝先に朱色〜赤みがかったオレンジ色 (ときにピンクがかる) の漏斗形の花 (直径 4〜5cm) が 2〜3 輪ずつ咲き、株全体が朱色に覆われる。開花のころは葉が少なく、花の色が株の表面をほとんど隠す
- 季節: 秋に春の葉が赤〜黄色になって落ち、冬は小さな濃い緑〜赤茶色の葉がまばらに枝先に残る
- 季節の形: 3 つ。夏 = 緑 (基本の形)、春 = 株の表面が朱色の花で覆われる (`_Hana`)、秋・冬 = 葉がまばらで赤茶色が混じる (`_Fuyu`)
- 生える所: 林のふち・明るい林の下・尾根・草原のふち・道ばたの土手 (understory, ridge)
