# ケヤキ (Zelkova serrata)
- 樹形: 落葉高木。樹高 20〜30m。太い幹が低い所 (2〜4m) から何本もの枝に分かれ、枝が斜め上に扇のように広がる、ほうきを逆さにした形の樹冠
- 幹: 灰白色〜灰褐色でなめらか、老木はうろこ状にはがれてまだら
- 葉: 3〜7cm の細長い卵形、縁にのこぎりの歯
- 季節の形: 4 つ。春 = 黄緑の新緑 (`_Haru`)、夏 = 緑 (基本の形)、秋 = 黄〜赤茶 (`_Aki`)、冬 = 細かい枝が扇形に見える枝だけ (`_Fuyu`)
- 生える所: 集落・屋敷林・神社・街路 (farm)
