# イロハモミジ (Acer palmatum)
- 樹形: 落葉高木〜小高木。樹高 6〜15m。幹は 1〜3 本、低い所から細い枝が斜め上〜横へ何段にも広がり、枝先は少し垂れる。樹冠は横に広い半球〜傘形 (幅は高さの 1.2〜1.5 倍) で、細かい葉が薄い層になって段々に重なり、光が透ける。谷・川沿いでは水の上へ枝を張り出す
- 幹: 灰褐色〜緑がかった灰色でなめらか、細い。太さ 15〜30cm。若い枝は緑〜赤みがかる
- 葉: 4〜6cm の手のひら形、深く 5〜7 つに裂け、ふちに細かいぎざぎざ。夏は明るい緑〜緑で、樹冠は軽く繊細に見える
- 花・実: 4 月、新芽と一緒に小さな赤い花の房。夏〜秋に赤い羽根の付いた実 (プロペラ形) が葉の上に点々と
- 季節: 4 月の新芽は黄緑〜赤みがかった黄緑。11 月中旬〜12 月上旬に、まっ赤〜朱色〜オレンジに紅葉 (1 本の中でも赤と黄が混じることがある)。冬は葉がなく、細い灰色の枝が細かく分かれて見える
- 季節の形: 4 つ。春 = 黄緑に赤が混じる新芽 (`_Haru`)、夏 = 緑 (基本の形)、秋 = まっ赤〜朱色〜オレンジの紅葉 (`_Aki`)、冬 = 葉を落とした細かい灰色の枝だけ (`_Fuyu`)
- 生える所: 谷・川沿い・林のふち (forest)、高い木の下 (understory)。神社・寺の境内
