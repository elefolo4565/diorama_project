# アカギ — Bischofia javanica

## 制作前に決めた樹形

太く少しねじれる単幹が地上 3〜6m で何本もの太枝に分かれる。裸の幹は下の約 20〜25%。枝は斜め上から横へ大きく張り、幅が樹高の約 1〜1.5 倍ある不規則な丸いドームを作る。葉の房の間に隙間を残す。老木は幹のこぶと張り根があり、林縁の個体は明るい側へ枝を広げる。

- A: 20m、太さ約 1.1m。6 本の太枝、ねじれとこぶのある成木。
- B: 16m、太さ約 80cm。5 本の太枝が片側へ広がる集落の木。
- C: 15m、太さ約 56cm。4 本の上向きの主枝、やや狭い樹冠の若い高木。

## 共通メモへの対応

基準は `plants/notes/akagi.md`。3 枚の小葉がまとまる複葉を、長い葉柄と一緒に自作する。小葉は 8〜15cm の卵形で先をとがらせ、細かい鋸歯を付ける。明るい緑のつやのある葉、赤褐色〜紫褐色の樹皮と明るい剥離跡を描く。花と実は遠目に目立たないため省略し、季節の形はメモどおり 1 つ (seasons=15)。

低地の林・谷沿いと集落の大木なので habitat=forest,farm、share は A=.030、B=.025、C=.020。自生を条件とするため regions=okinawa とする。メモには奄美・小笠原もあるが、[環境省の奄美の外来植物資料](https://kyushu.env.go.jp/okinawa/awcc/images/alien-priority/15.pdf) と [森林総合研究所の小笠原での導入の説明](https://www.ffpri.go.jp/ftbc/business/gyoumusyoukai/genba/r3nendo/r4_0223.html) に従い、kyushu と kanto は含めない。特徴メモの形と葉の基準は保つ。

写真・外部画像・モデルは使用せず、自分で形と PNG を作る。

## プレビューでの修正

1. 初稿の正面・横と Blender 画像を見て、幹のねじれと樹冠の上下差を加えた。小葉が大きめだったため、板の大きさを調整して 8〜15cm に近づけた。赤褐色の幹が枝分かれして樹冠の中へ続く姿を保った。
2. 二稿を見て、A/B の幹に局所的なこぶを付け、若い C は小さいこぶだけにした。下の葉房を約 3 分の 2 に減らし、高さを散らして自然な下端にした。
3. Blender で幹のこぶの輪郭が角ばって見えたため、幹の縦方向の分割を増やして滑らかにした。

全個体の habitat は forest, farm。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: okinawa。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。
