# テリハボク — Calophyllum inophyllum

## 制作前に決めた樹形

短い単幹が高さの 16〜22% で太い枝 3〜5 本に分かれる。裸の幹は下の約 15〜25%。主枝は斜め上から横へ広がり、密な丸い〜横長の卵形の樹冠へ入る。幅は高さの約 1〜1.3 倍。根元を少し張り出し、先に行くほど枝を細くする。

- A: 9.5m の成木。直径約 49cm の短い幹と横広がりの枝、幅約 10〜11m の丸い樹冠。
- B: 4.7m の海風を受ける個体。低く 3 本へ分岐し、風下へ傾く。風上側の肩を低くする。
- C: 6.5m の若木。幹は細く、少し上向きの枝と狭めの樹冠。成木の縮小にはしない。

## 共通メモへの対応

基準は `plants/notes/terihaboku.md`。葉は対生する厚い楕円で先を丸くし、細い平行葉脈を多数描く。葉長は板の寸法から約 12〜17cm。濃緑で光沢が強い葉、灰褐色の浅い縦割れの樹皮を自作する。花・実は遠くで目立たないので省略し、指定どおり一年中共通の 1 形、seasons=15。

海岸の防潮林・砂浜の奥に生えるため habitat は coast。ほかの海岸樹と混じるよう share は A=.035、B=.025、C=.020。自然分布の沖縄・八重山を okinawa、小笠原を kanto で表す。地方単位のため kanto の本州にも選ばれうる制約がある。

外部アセット・写真は使用せず、特徴メモの数値と言葉から形と絵を作る。

## プレビューで直す点

1. 初稿の正面・横と Blender 画像を見て、輪郭が均一だったため房の張り出しを変え、B の風上側の肩を低くした。
2. 二稿を見て下端の密度を約 3 分の 2 に落とし、高さを散らした。主枝途中から下向きの小枝と葉房を足し、下の輪郭と枝分かれを自然にした。

B は風で低くなった横広の個体を優先し、葉を含む最大幅は樹高の約 1.5 倍になる。メモの通常個体の 1〜1.3 倍より広い例として表す。

全個体の habitat は coast。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: okinawa, kanto。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py terihaboku` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
