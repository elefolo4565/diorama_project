# Claude からの直す指示 (Codex 版)

AGENTS.md のとおり、**ほかの作業 (沖縄の新しい種類) より先に、「状態」が空の行を上から 1 つずつ直す**。
1 PR = 1 種類。ブランチはその種類の `codex/plant-<種類>` (main を取り込み直してから直す)。
直して PR を出したら、その PR の中でこの表の「状態」を「済」にする (この表で変えてよいのはそこだけ)。
直す基準は `plants/notes/<種類>.md` の「季節の形」と、AGENTS.md の「季節の形のきまり」。

| 状態 | 種類 | 直すこと |
| --- | --- | --- |
| | ヤブツバキ (yabutsubaki) | いまは B だけが花の形で、しかも seasons=9 なので夏・秋に B の木が消える。A/B/C を一年中の基本の形 (seasons = 夏・秋の 2+4) にし、それぞれ同じ枝・同じ乱数の順の `_Hana` (冬・春の 8+1、`place_with` で基本の形と同じ位置) を作る。赤い花は直径 5〜7cm 相当の大きさで、樹冠の表面と中に点々と、遠目 (30m) でも赤が見える数にする |
| | トベラ (tobera) | 季節の形が無い。A/B/C それぞれに春の `_Hana` (seasons 1、`place_with`) を作り、基本の形は夏〜冬 (2+4+8)。枝先のロゼットの真ん中に白い花の房 (後に黄色くなる) を付け、遠目でも白が点々と見えるようにする |
| | シャリンバイ (sharinbai) | 春の形の花が薄い赤っぽい色に見え、白い花に見えない。花びらを白 (中心だけ少し赤) にし、房の大きさと数を増やして、株全体に白が点々と散って見えるようにする。名前は `_Spring` から `_Hana` にそろえる |
| | アラカシ (arakashi) | 季節の形が無い。A/B/C それぞれに春の `_Haru` (seasons 1、`place_with`) を作り、基本の形は夏〜冬 (2+4+8)。樹冠の表面の葉を銅色〜赤茶の新芽にし、黄褐色の垂れた花の房を混ぜる |

確かめ方は AGENTS.md と同じ (`python plants/check.py <種類>` で OK、preview を PR に貼る)。
UE での見た目は、マージの後に Claude がオーナーの PC で確かめて、見比べページに季節ごとの写真を足す。
