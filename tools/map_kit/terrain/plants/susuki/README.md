# ススキ (Miscanthus sinensis)

## 制作前に決めた株の形

- 根元の狭い範囲から密に葉が出る株立ち。A は大きな直立株 (75 葉・7 花稈)、B は土手で少し片寄る株 (61 葉・5 花稈)、C は若く低い株 (48 葉・4 花稈)。
- 葉の付く下 2〜4 割は細い葉鞘が重なる。葉は中心から立ち上がり、上半分で外に弓なりに曲がる噴水形とする。
- 葉先までの株幅は約 0.5〜1 m。稈は葉の上へ抜け、秋冬の全高は A 1.85 / B 1.55 / C 1.28 m を目安にする。
- 根元はほぼ直立、葉身は横から下へ垂れる。B のみ土手の斜めの姿を想定し、花稈を約 5 度傾ける。
- 穂は細い枝 16 本の扇状で、15〜30 cm の銀白色の毛を自作する。塊の球や太い円錐にはしない。

## 共通メモへの対応

`plants/notes/susuki.md` の季節指定に従い、春夏の葉だけ (seasons=3)、秋の銀白色の穂 (`_Aki`, 4)、冬の茶〜黄土色の葉と古い穂 (`_Fuyu`, 8) を各個体に作る。

葉は 50〜80 cm、幅 1〜2 cm、中央に細い白い筋。季節ごとに乱数を引き直さず、同じ葉・葉鞘の頂点から色違いを作る。秋冬の稈・穂も同じ形。`place_with` で春夏の相手と位置・向きを共有する。

habitat は grassland / farm、share は A 0.08 / B 0.06 / C 0.04。草原とあぜに疎密を作る目安。分布は [国立科学博物館のススキの説明](https://www.kahaku.go.jp/research/db/botany/wild_p100/autumn/27_susuki.html) に基づき全国の 10 地方とする。

葉・穂の 1024×1024 RGBA は手続き描画で自作する。草なので樹皮はなく、葉鞘と花稈には名前を付けた単色材質を使う。外部画像・アセットは使わない。

## 画像を見た改稿

1. 初回は葉の付く高さが狭い範囲に集まり下部が裸だったので、根元近くから高い節まで葉を分散し、葉数を約 1.7 倍に増やした。
2. 2 回目の Blender 画像で穂が一様な三角形に見えたので、細い主軸の異なる高さから左右に 16 本の枝を出す絵に直し、穂の板を 3 枚から 2 枚へ減らした。葉先も長さごとに少し垂らし、噴水形の輪郭を崩した。

全個体の habitat は grassland, farm。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kyushu, okinawa, shikoku, chugoku, kansai, chubu, kanto, tohoku, hokuriku, hokkaido。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py susuki` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
