# ソテツ (Cycas revoluta)

## 制作前に決めた樹形

- A は少し曲がった単幹の成株 (全高 2.7 m)、B は二又の古い幹と根元の子株 (2.4 m)、C は低い子株が 2 頭並ぶ若い群れ (1.2 m)。幹の数・頭の位置・葉数を変える。
- 幹の高さは成株で約 1〜2 m、直径 20〜40 cm。暗い灰褐色のうろこ状の古い葉の基部を残す。根元から頂部までほぼ同じ太さのまま、少し先を細くする。
- 幹の上部の頂から羽状葉が放射状に出る噴水形。葉が幹の上 2〜3 割にかかり、下の幹は見える。若株は地面近くに葉が広がる。
- 内側の葉は斜め上、中段は水平、外側は下へ曲がる。頂の下には古い茶色の葉が垂れて残る。成株の頭に 30〜60 葉を目安にする。
- 幹は少し傾きくねるが、海風で全葉を一方向に倒さない。B は古い幹の二又、根元の子株の高さの違いを強調する。

## 共通メモへの対応

基準は `plants/notes/sotetsu.md`。0.8〜1.5 m の硬い羽状葉、細長い針状の小葉、濃緑のつや、古い葉の茶色の裾を自作する。うろこ状の樹皮の色・法線と葉のアトラスも自作する。

指定は一年中ほぼ同じ 1 形 (seasons=15)。雄・雌の生殖器官や種を一年中固定することを避け、葉と幹を中心に作る。小さい子株では頭当たりの葉数を控える。

南九州の海岸・岩場に限定して、PLAN.md 指定どおり habitat は coast、regions は kyushu のみ。share は A 0.015 / B 0.012 / C 0.010 とし、海岸全体がソテツで埋まらない目安にする。九州南部だけに絞る受け口は現在の地方区分より細かいため、細かな配置は取り込み後に調整が必要。

外部アセット・画像・モデルは使っていない。

## 画像を見た改稿

1. 初回の真上画像に頂部の空洞が見えたので、葉の基部が集まる頂と短い若葉を加えた。幹の半径に凹凸を付け、低い子株の葉が地面の下へ抜けないよう葉先を上げた。
2. 2 回目の Blender 画像で葉と幹の間にすき間が目立ったので、葉の絵の細い部分を補う葉柄・中軸を立体で幹の頂から葉身までつないだ。頂を低い丸みにし、根元の深い埋まりを 2 cm 程度へ抑え、外側の葉をさらに垂らした。

## 成果物と配置

| C | 1.2 m | 2,244 | coast | 0.01 | 15 |

全個体の habitat は coast。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kyushu。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py sotetsu` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
