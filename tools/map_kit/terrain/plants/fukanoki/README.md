# フカノキ — Schefflera heptaphylla

## 制作前に決めた樹形

細くほぼまっすぐな単幹が高さの約 55〜65% から少数の枝に分かれ、枝先だけに葉がまとまる。裸の幹は下の約半分。樹冠は小さい丸い傘〜縦長で、枝先ごとの葉の塊は離れ、隙間から枝が見える。林内なので海風の強い曲がりは付けない。

- A: 7.8m、幹の直径約 26cm、4 本の主枝。枝先に小さな傘が重なる成木。
- B: 6.0m、直径約 20cm、3 本の主枝。林縁で明るい側へ少し枝を伸ばす。
- C: 5.0m、直径約 14cm、2 本の上向きの主枝。狭く縦長の若木。

## 共通メモへの対応

`plants/notes/fukanoki.md` を基準にする。7〜10 枚の小葉が長い葉柄の先から放射状に開く掌状複葉を自作し、枝先に複葉が 5〜10 枚集まる房にする。小葉は 10〜18cm の先のとがる長楕円、表はつやのある濃緑。細い幹は灰白色で皮目の点と葉痕の輪。花と実は葉の姿を基準にするため省略し、指定の 1 形 (seasons=15) を作る。

九州南部〜沖縄・八重山の林内・林縁なので regions=kyushu,okinawa、habitat=forest。大きな照葉樹に混じる小さい高木として share は A=.025、B=.020、C=.015。

外部の写真・画像・モデルを使わず、葉と樹皮の PNG・形を自作する。

## プレビューでの修正

1. 初稿の正面・横と Blender 画像で複葉が立ちすぎていたため、上向きに開く向きへ変え、房の高さをばらした。C の房は密すぎたので数を減らし、灰白色の樹皮には皮目の点を足した。
2. 二稿を見て、下側の房では複葉を 5 枚程度に減らし、高さを散らした。少数の主枝と、枝先ごとに離れた葉冠の間の隙間を残した。

全個体の habitat は forest。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kyushu, okinawa。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py fukanoki` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
