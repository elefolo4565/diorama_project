# トベラ

和名: トベラ。学名: *Pittosporum tobira*。

## 制作前に決めた樹形

海岸に自生する、丸くこんもりした常緑低木を作る。園芸品種の斑入り葉や均一に刈り込んだ生け垣にはしない。

- 根元から 3〜6 本の細い幹が立ち、低い所で枝分かれする株立ち。幹の露出は樹高の約 5〜18% に抑える。
- 樹冠は丸いドームから横長の半球。葉の下端は水平にそろえず、下部ほど房を減らして小さな枝と隙間を残す。
- 主枝は鉛直からおおむね 25〜55 度に開き、先端を上へ曲げる。側枝は主枝から 35〜70 度に開き、樹冠の中でさらに分かれる。
- 葉は厚い長倒卵形、先端は丸く、縁は鋸歯のない形。葉柄側を細くし、枝先に葉を密生させる。葉の板には枝先の集まりを描く。
- 房は樹冠の表面付近に置き、幹の周囲の内部は空ける。房の大きさと深さを変え、外と上を明るく、奥と下を暗くする。

| 形 | 生え方 | 樹高の目安 | 幹と樹冠 |
| --- | --- | --- | --- |
| A | 風の弱い海岸林縁の成木 | 2.4 m | 5 本の幹、丸い広いドーム、低い裾 |
| B | 海風を受ける岩場の株 | 1.65 m | 6 本の幹、風下へ流れる幅広い低い半球 |
| C | 林縁の若い株 | 1.1 m | 3 本の幹、幅を抑えた丸い樹冠、成木とは異なる枝の配置 |

## 比較で確認したこと

制作前に `plants/_ubamegashi/review/ubamegashi_preview.png` と、`plants/ubamegashiopus.py` を `check.py` で描いたプレビューを見比べた。
不採用版に見られた長い裸の幹と水平な樹冠下端を避け、採用版の低い枝分かれ・不規則な裾・個体ごとの生え方の違いを基準にする。

## プレビューを見て直した点

1. 初稿では正面と真上に大きな空洞があり、丸く密な低木に見えなかった。枝先の葉数と房数を増やし、上面に房を配置し直した。内部を埋めずに表面の葉を重ね、露出した主枝を減らした。
2. 1 回目の修正後も正面中央に窓状の隙間が残っていた。外周の中段に房を足し、幹の周囲の空間を保ちながら視線が抜けすぎる箇所を減らした。B は風上の肩を低くして風下へ流し、C は幅を縮めて若い株の姿にした。
3. Blender の斜め上からの画像で A/B の手前上部に抜けが残ったため、その表面にも房を追加した。葉の板は面の向きを外向き法線とそろえて書き出すようにした。

## 自然分布と形態の参照

[森林総合研究所 九州支所: トベラ](https://www.ffpri.go.jp/kys/business/jumokuen/jumoku/zukan/tobera.html) の文章を参考にした。
海岸の常緑低木、灰褐色の枝、厚い長倒卵形の葉が枝先に密生するという特徴を反映する。
外部の画像・モデル・アセットは使用しない。

## 配置と成果物

`habitat` は全形状とも `coast`。A/B/C の `share` はそれぞれ 0.035 / 0.025 / 0.020、合計 8% を目安にする。
海岸林縁の成株・風の強い場所の低い株・若い株を混ぜ、同じ樹形ばかりが並ぶのを避ける。
自然分布に合わせて九州・沖縄・四国・中国・関西・中部・関東・東北・北陸で使用する。常緑の葉を一年中置く `seasons=15`。

| メッシュ | 三角形数 | GLB の大きさ |
| --- | --- | --- |
| SM_FD_Tobera_A | 3,648 | 313,100 バイト |
| SM_FD_Tobera_B | 3,416 | 291,548 バイト |
| SM_FD_Tobera_C | 2,328 | 202,500 バイト |

葉のアトラスは 1024×1024 RGBA、不透明部分は約 27.2%。4 通りの枝先を収め、透明部分の縁へ葉色を広げている。
樹皮は平滑な灰褐色〜黒褐色で、色と法線は 1024×1024 RGB、上下左右につながる。法線の向きは既存の `bark.normal_map` と同じ。
GLB は画像を含めず、1 メッシュ・2 マテリアル。ノード変換・骨・アニメーション・当たり判定は含めない。
原点は株の地面中心、メートル単位、glTF の Y 上で書き出している。葉は両面マテリアルを使うため裏面を重ねていない。

最終的な UE の色・光・風の動きはマージ後に確認する。
