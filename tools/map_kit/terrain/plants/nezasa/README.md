# ネザサ (Pleioblastus argenteostriatus f. glaber)

## 制作前に決めた樹形

- 地下茎から何本も細い稈が立つ面状の群落。A は高さ 1.65 m の密なやぶ (38 稈)、B は 1.1 m の細長い群落 (30 稈)、C は刈られるあぜの 0.6 m の低い群落 (22 稈)。単なる同形の拡大縮小にはしない。
- 下の 3〜4 割は稈が透け、茶色の古い稈・枯れ葉が混じる。上の 5〜6 割で枝と葉が絡む。
- 輪郭は横に続く低い面で、上面は葉の重みで周囲へ垂れ、稈ごとの高さで凹凸を付ける。
- 稈は鉛直から約 5〜15 度、上の枝は横から斜め上へ開く。枝先に細長い葉を 5 枚ずつ扇状に付ける。
- 林縁・あぜの姿なので強い海風の傾きは付けない。外側の葉をより下へ向ける。

## 共通メモへの対応

基準は `plants/notes/nezasa.md`。明るい緑〜黄緑、10〜25 cm の披針形の葉、細い節のある稈、下部の枯れ葉を自作する。葉のつやは弱くする。

春〜秋は基本形 (seasons=7)、冬は同じ頂点・UV・透過輪郭を保って葉色を淡くし、縁を白く枯らす `_Fuyu` (8)。各冬形に `place_with` を書き、稈と葉の位置が季節で跳ばないようにする。

habitat は understory / farm。木を覆い尽くさない目安として share は A 0.10 / B 0.08 / C 0.06。西日本のネザサとして九州・四国・中国・関西・中部・北陸に対応させ、アズマネザサとの区別のため関東以北は含めない。

外部画像・モデルは使用せず、葉と枯れ色の絵は自作する。花はメモの季節数に含まれないので付けない。

## 画像を見た改稿

1. 初回は中央に丸い空洞が見えたので、稈の間隔を詰め、半数の枝を内側にも伸ばした。葉面の傾き・ひねりを増やし、正面でも披針形の面が見えるようにした。冬の白い縁も太くした。
2. 2 回目は上面に直線的な葉が目立ったので、上の枝と葉先を曲げて外へ垂らした。下部の古い葉と直立する稈は残し、面状のやぶの上下の違いを付けた。

全個体の habitat は understory, farm。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kyushu, shikoku, chugoku, kansai, chubu, hokuriku。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py nezasa` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
