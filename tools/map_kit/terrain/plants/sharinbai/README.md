# シャリンバイ (Rhaphiolepis indica var. umbellata)

## 制作前の樹形

基準は `plants/notes/sharinbai.md`。メモを共通の基準とし、写真と他作者の `*opus.py` は開かずに制作する。

- 根元近くから 4〜6 本に分かれる株立ち。黒っぽい灰褐色の枝が立ち上がり、下部の裸の枝は樹高の約 10〜15% に抑える。
- 樹冠は下まで葉のある丸い低木。外殻は大小の房に分け、内部は葉で埋めず、下端は枝先ごとに高さが異なる。
- 中枝は斜め上へ、末端は三方向へ車輪状に分かれる。その先で厚い倒卵形の葉を輪生状に集める。葉脈とわずかに巻く縁を控えめな明度差で表す。
- 葉は 4〜8cm。主に濃緑とし、アトラスの一部だけ黄緑・赤褐色の新葉を混ぜる。
- A は 2.65m の丸い株、B は 1.85m の横に広い多幹株、C は 1.05m の崖の低木。枝数・樹冠の縦横比・株立ち数を変える。風は B/C が少し片側へ張る程度にとどめる。
- 春形は枝先に小さな白い 5 弁花を房状に散らす。花の中心は赤い。1 輪を約 1〜1.5cm とし、大輪に誇張しない。

## 共通メモへの対応

海岸の崖・岩場・海辺の林縁を表す `coast` に配置する。割合は A/B が各 2.5%、C が 2% (合計 7%)。トベラなどと混じる海岸低木として、単独で海岸を占めない割合を選んだ。
3 個体それぞれに同じ枝と葉の通常形・春の開花形を作り、`place_with` で同じ位置と向きにする。通常形は夏秋冬 (14)、開花形は春 (1)。秋冬の黒紫の小果は遠景で小さいため省略する。

## 分布の確認

[森林総合研究所の分布データ](https://www.ffpri.go.jp/labs/prdb/sharinbai.html) の文章から、暖地海岸の低木層・風衝低木群落に対応させた。写真を開いたり、画像を素材として利用したりしていない。

## 画像確認後の改稿

1. 初稿の正面・横では葉が薄い棚に見えた。板の約 2/3 を外向きに立て、輪生状の葉が横からも見えるようにした。葉の重なりすぎる扇形をやめ、枝先を囲む輪状のアトラスに描き直した。花は葉に埋まらない枝先の外側に移した。
2. 第 2 稿では特に B/C の中央が透けすぎた。細枝の断面を減らして葉へ三角形を振り替え、1 枝先の板を 6 枚から 9 枚へ増やした。板を外殻の接線方向にもずらし、樹冠内部を詰めずに房同士の隙間を小さくした。アトラスも 3 段の輪生状の葉へ増やした。
3. Blender の斜視で見える上面中央と前後の隙間を、小さな外殻の房で補った。低木の丸い量感と枝の透けを両立し、4,000 三角形未満に収めた。
4. 花の拡大確認で葉に隠れる房があったため、各枝先の外向きの葉面を求め、その少し外へ花を移した。花自体は拡大せず、小輪の寸法を保った。

全個体の habitat は coast。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kyushu, okinawa, shikoku, chugoku, kansai, chubu, kanto。
春の開花形は通常形に `place_with` で対応し、枝・葉の頂点を共有する形から花だけ追加した。通常形は `seasons=14`、開花形は `1`。月単位の指定がないため 4〜5 月を春で近似する。秋冬の実は 1cm と小さく、今回の遠景形では省略。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮の色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py sharinbai` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
