# アダン (Pandanus odoratissimus)

## 制作前に決めた樹形

- A は全高 4.4 m の 6 頭の成株、B は 3.4 m の斜めに広がる 4 頭の株、C は 2.2 m の 3 頭の若い株。細い幹が 2〜3 回二又になり、それぞれの枝先に葉の束を付ける。
- 下の約 5〜6 割に幹とタコ足状の支柱根が見え、上の枝先に細長い葉が密な噴水形になる。幅は複数の頭の広がりで変える。
- 幹は鉛直から約 15〜35 度傾き、二又の枝は外へ開く。葉はらせん状に付け、内側は斜め上、外側は下へ大きく垂らす。
- 海岸の風にさらされた B は幹と枝を片寄らせる。A/C の葉先は個別に揺らぎ、同方向にはそろえない。
- 幹の下から太さ約 3〜6 cm の根が斜めに何本も伸び、地面に刺さる。葉は長さ 1〜1.5 m、幅 4〜6 cm の剣形、古い黄褐色の葉を束の下に残す。

## 共通メモへの対応

基準は `plants/notes/adan.md`。灰褐色の幹の輪の模様、葉の縁の小さいとげ、濃緑〜青緑の葉、枝から下がる直径 15〜20 cm の凹凸のある集合果を自作する。

メモ指定は一年中の 1 形 (seasons=15)。成株には緑とオレンジの集合果を少数付け、若株は実を控える。habitat は coast、share は A 0.035 / B 0.025 / C 0.020。砂浜の奥に小さな株群を作る目安にする。奄美・沖縄の自然の海岸植生として regions は kyushu / okinawa。小さな葉のとげと実の分果の数は遠景用に簡略化する。

葉・幹の PNG と全ての形を自作し、外部画像・アセットは使わない。

## 画像を見た改稿

1. 初回の若株は葉が長すぎて幅が大きくなったため、幹と葉の実寸の比率を調整した。葉長 1〜1.5 m 程度に収まるよう幹の高さを合わせ、葉先の角度をばらつかせた。集合果の面は外向きにそろえた。
2. 2 回目は長い幹が一か所から束状に分かれて見えたため、途中で繰り返し二又になる枝の骨格に組み替えた。枝先の葉数を増やし、古い葉は下へ残した。支柱根の上端は実際の幹の位置に合わせた。

追加検査で、集合果の上下の極点に面積 0 の三角形が残っていたため除いた。すべての法線が単位長になることを確認して納品する。

全個体の habitat は coast。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kyushu, okinawa。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py adan` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
