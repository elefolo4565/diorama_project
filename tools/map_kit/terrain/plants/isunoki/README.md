# イスノキ (Distylium racemosum)

## 制作前の樹形

共通の基準は `plants/notes/isunoki.md`。写真や `*opus.py` は見ず、形・葉・樹皮を自作する。

- 単幹。A/B は地上約 3m、全高の約 2 割で 4〜5 本の主枝へ分かれる。枝は曲がりながら斜め上へ伸び、樹冠内部まで続く。
- A は 14.5m の古木。幹径約 74cm、根張りが太く、ねじれる灰白色の幹と根際の筋を作る。丸く密な樹冠。
- B は 11.5m、幹径約 54cm の成木で、A より細い主枝と小さい樹冠。
- C は 10m、幹径約 30cm の若木。縦長の卵形〜円錐形とし、下の方まで葉を付ける。単なる縮小にしない。
- 裸の幹は A/B で約 20%、C は約 10%。林内の木として強い風の傾きは付けない。
- 4〜8cm の全縁の小さな楕円葉を交互に密に付け、アトラスの一部には小さな丸い虫こぶを描く。赤い小花は遠景で目立たないため省略。
- 樹冠の外殻に大小の房を置き、内側は空ける。下端をばらし、奥・下を頂点色で暗くする。

## 季節と配置

メモどおり通年 1 形 (`seasons=15`)。社寺林・暖地の照葉樹林の高木層を表す `forest`。A/B/C は 2.5%・2%・1.5% (合計 6%) とし、他の照葉樹と混生させる。
地方は関東以西・四国・九州・琉球に対応させる。[森林総合研究所の記載](https://www.ffpri.go.jp/kys/business/jumokuen/jumoku/zukan/isunoki.html) は分布の文章だけを確認した。写真は閲覧・利用していない。

## 画像確認後の改稿

1. 初稿では古木の根際の広がりが弱く、樹冠の輪郭もそろっていた。根際を太く広げ、樹冠外殻の房を大きな波形にずらして凸凹を増やした。
2. 第 2 稿の正面・横では樹冠中央の透けが強すぎた。外殻の板を約 25% 増やし、下端は房の高さと枚数を減らして散らした。古木の幹にはねじれる縦のうねりも形として加えた。

全個体の habitat は forest。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kyushu, okinawa, shikoku, chugoku, kansai, chubu, kanto, hokuriku。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py isunoki` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
