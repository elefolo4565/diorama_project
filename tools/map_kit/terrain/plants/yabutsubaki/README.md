# ヤブツバキ (Camellia japonica)

## 制作前に決めた樹形

林内の常緑小高木を作る。トベラの横長の海岸低木とは生え方を変え、枝先の赤い花は平開しすぎない椀形にする。

- A は 5.2 m の単幹の個体。幹は地上約 15〜20% まで見え、低い側枝から縦長の卵形の樹冠が始まる。
- B は 3.7 m の根元で 2 本に分かれた個体。林縁で横へ張る不規則な丸い樹冠。冬〜春の開花個体とし、葉を背景に赤い 5 枚の花弁と黄色い雄しべの筒を少数見せる。
- C は 2.2 m の若木。細い単幹から短い枝が斜め上へ出る。幅を抑えた卵形で、A の縮小にはしない。
- 主枝は斜め上へ約 25〜50 度に開き、外側の細枝は緩く弧を描く。林内の姿なので海風による一方向の傾きは付けない。
- 葉は濃緑の楕円形、先が鋭く、縁に細かい鋸歯。小枝に互生する葉の集まりを 2×2 の透過画像に自作する。
- 房は樹冠の表面近くに置き、内部には葉の板を詰めない。下部は房を減らし、水平な下端を作らない。幹・主枝は樹冠の中で細く分かれる。

## FIXES.md の修正への対応

A/B/C の基本形は葉だけで夏・秋 (6)、_Hana は冬・春 (9) とした。B が夏秋に消える欠陥を直し、全個体に赤い花を分散させた。追加指示「2 回目」に従い、C はそのまま、A/B の花数を前の版の約 2.2 倍、直径を 1.4 倍 (約 6cm→8.4cm) にし、樹冠の表面より外へ出した。A/B の花の大きさは遠目の見え方を優先した表現。元の B の花・雄しべだけを除き、幹・枝・葉は同じ座標のまま残した。

既存 GLB の幹・枝・葉のバッファを再生成せず、同じ頂点・法線・UV・頂点色・インデックスに花を追加した。季節形には `place_with` を指定し、季節のビットは各個体で 1/2/4/8 を一度ずつ使う。元の枝葉と季節形が数値で完全一致することを確認した。
