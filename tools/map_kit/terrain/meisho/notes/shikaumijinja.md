# 志賀海神社 (福岡市東区志賀島。綿津見三神をまつる海の神の総本社)
- 場所: 志賀島の東、志賀島橋に近い山の中腹。海ぎわの道路から北へ上っていく
- 参道: 道路ぎわに石の鳥居。そこから石の階段 (76 段、両側に手すり) を上り、木々に囲まれた石畳の参道 (石灯籠が並ぶ)。
  その先の広い石段 (手すりが 3 列) の上に楼門
- 楼門: 2 階建ての門。白木 (古びた茶色) の柱と壁、2 階に縁と欄干、上下 2 段の屋根は緑青の銅板 (淡い緑)。扁額
- 境内: 楼門の奥の平らな境内に拝殿 (白木、緑青の屋根、正面に向拝、石段、金の扁額)。拝殿の奥に本殿。
  西に今宮神社 (小さな拝殿と本殿)、拝殿の東の参道ぞいに鹿角堂 (白壁に木の格子、緑青の屋根、高い石の基礎。
  奉納された鹿の角を納める。そばに鹿の像)
- 色: 朱塗りはなく、白木の茶色・白壁・緑青の緑・石の灰色。まわりは濃い照葉樹の森
- 季節の形: 一年中 1 つ
- 建物の場所と大きさ: OpenStreetMap の輪郭 (拝殿・本殿・今宮神社・鹿角堂) と石段・参道の線 (© OpenStreetMap contributors, ODbL)
