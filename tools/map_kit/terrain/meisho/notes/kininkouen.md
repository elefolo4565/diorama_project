# 金印公園 (福岡市東区志賀島、県道 542 号ぞい)
- 場所: 志賀島の南西の海ぎわ。道路の山側の斜面にあり、道路の向かいは海 (能古島と福岡の街が見える)
- 道路ぎわ: 「漢委奴国王金印発光之処」の碑。明るい灰色の花崗岩の細長い角柱 (高さ 4〜5m、太さ 0.7〜0.8m) が、
  大きな自然石の台 (高さ 1m 余り) の上に立つ。まわりは石を組んだ植え込み。碑の前は道路と同じ高さの小さな前庭
- 石段: 碑の横から山の斜面を上る、幅 2.5〜3m の石の段。両側に金属の手すり。段の両脇は木と植え込みで覆われている
- 上の広場: 丸い石畳の広場 (直径 10m ほど)。内側に明るい色の円、中央に金印をかたどった四角い石 (暗い台の上)。
  まわりに説明板 (白い板、上に紺の帯) が数枚。海側は手すりで、海と能古島がよく見える
- 色: 石と石畳は灰色、碑は明るい灰色、手すりは銀色。まわりは濃い緑の照葉樹
- 季節の形: 一年中 1 つ
