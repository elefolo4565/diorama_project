# Claude からの直す指示

Codex 版の種類で、特徴メモや決まりと合っていない所の直し方です。**新しい種類を作るより先に**、表の上から直してください。
直したら、その種類のブランチ (`codex/plant-<種類>`) に push し、`python plants/check.py <種類>` で OK を確かめ、preview を PR に貼る。
このファイルで変えてよいのは「状態」だけ (直したら「済」)。

| 状態 | 種類 | 直すこと |
| --- | --- | --- |
| | トベラ | 春の花の形が無い。A/B/C それぞれに `_Hana` (seasons=1 = 春、`place_with` で基本の形と同じ位置、基本の形は seasons=14 (夏・秋・冬)) を作り、白い花の房を枝先に。遠目でも白が点々と見える大きさと数にする |
| | アラカシ | 春の形が無い。A/B/C それぞれに `_Haru` (seasons=1 = 春、place_with) を作り、銅色の新芽と黄褐色の花の房で樹冠の表面を明るくする |
| | ヤブツバキ | 花があるのが B だけで、B は冬・春しか出ないため夏・秋に木が消える。A/B/C を一年中の基本の形 (葉だけ、seasons=6 = 夏・秋) にし、それぞれ同じ枝の `_Hana` (冬・春、seasons=8\|1、place_with) を作る。赤い花は直径 5〜7cm 相当で、遠目にも赤が点々と見える数と大きさにする |
| | シャリンバイ | `_Spring` の花がうすい赤で白く見えない。花を白 (中心が少し赤) にし、遠目にも白く見える数と大きさにする |
