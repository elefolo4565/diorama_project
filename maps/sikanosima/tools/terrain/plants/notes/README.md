# 特徴メモ (種類ごとの見た目の基準)

`<種類のローマ字>.md` に、写真 (iNaturalist・Wikimedia Commons など、利用条件が許すもの) を見て書いた特徴を置きます。
Claude も Codex も、このメモを同じ基準として形と絵を作ります。写真そのものはリポジトリに入れません。

書き方 (例: `yabutsubaki.md`):

```
# ヤブツバキ (Camellia japonica)
- 樹形: 単幹〜2 本立ち。樹高 5〜7m (林の中)。樹冠は縦長の卵形、幅は高さの 0.6〜0.8 倍。下枝は地上 0.5〜1m から
- 幹: 灰白色でなめらか、太さは樹高 7m で 15〜20cm
- 葉: 5〜10cm の楕円、先がとがる。濃い緑で強いつや。枝に互い違いに密に付く
- 花・実: 赤、直径 5〜7cm、半開き。12〜4 月。樹冠の表面に点々と (1 房に 1〜2 輪)
- 生える所: 海に近い林・社寺林の中 (forest)。九州〜東北南部の沿岸
- 見た写真: <URL> (CC BY 4.0, 撮影者名) / <URL> (CC0) / ...
```
