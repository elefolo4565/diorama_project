# オオハマボウ (Hibiscus tiliaceus)
- 樹形: 常緑の低木〜小高木。高さ 3〜8m。根元近くで幹が何本にも分かれ、枝は横〜斜め下へ長く伸びて地面をはうこともある。株は横に広がるこんもりした塊 (幅は高さの 1.5〜2 倍)。河口や海岸では隣の株と枝が絡み合い、低いやぶの帯になる
- 幹: 灰褐色〜灰色、なめらかで浅い割れ目。くねって斜めに伸び、太さ 10〜25cm
- 葉: 10〜15cm の丸いハート形、先が短くとがる。厚めで明るい〜ふつうの緑、つやは弱く、裏は白っぽい。長い葉柄で枝にまばらに付き、葉が重なって樹冠の表面をうろこのように覆う
- 花・実: 夏 (6〜9 月) に直径 6〜8cm の黄色い花、中心が濃い赤紫。1 日でしぼむと橙〜赤に変わって落ちる。花は葉の上に点々と (樹冠 1m 四方に数輪)
- 季節の形: 2 つ。秋〜春 = 葉だけ (基本の形)、夏 = 黄色い花 (`_Hana`)
- 生える所: 海岸・河口・マングローブのふち・集落の防風垣 (coast)。奄美〜沖縄・八重山
