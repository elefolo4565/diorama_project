# グンバイヒルガオ — Ipomoea pes-caprae

## 制作前に決めた株の形

砂の上を赤紫〜緑のつるが横にはい、節から長い葉柄を立てる、低いじゅうたん状の群落。高さは 10〜30cm。立ち上がる幹や木の枝は作らない。葉は丸く幅広い軍配形で、先が浅くへこみ、中央で少し折れて斜め上を向く。

- A: 約 18cm。8 本のつるが重なる群落の中の一区画。つるをほぼ平行に走らせる。
- B: 約 16cm。5 本が広がる砂浜の縁。裸の砂へ伸びるつると隙間を残す。
- C: 約 12cm。3 本の短いつるが交差する新しい群落。

## 共通メモへの対応

`plants/notes/gunbaihirugao.md` を基準に、5〜10cm の厚い葉を長さ 5〜10cm 程度の葉柄の先に付ける。つるは直径約 0.5〜1cm。A は数 m のつるの一区画を表す (何十 m もある群落全体は一つの GLB にしない)。夏だけ、直径 5〜6cm の桃〜赤紫色のラッパ形の花を、1m 四方に数輪程度の密度で葉の間に出す。花の中央は濃くする。

季節は指定の 2 つ。葉だけの基本は春・秋・冬 (13)、夏の `_Hana` は 2。つる・葉柄・葉板の形を変えず、花だけを加除する。

四国・九州南部〜沖縄の波が届かない砂浜の奥を表すため、regions=shikoku, kyushu, okinawa、habitat=coast。海岸の低い被覆として share=A .025、B .020、C .015。砂浜と岩場を分ける habitat が無いため、coast 内で砂浜だけに限定する点は現在の受け口では表せない。

外部の写真・画像・モデルを使わず、つる・葉・花と PNG は自作する。

## プレビューでの修正

1. 初稿の真上では葉がそろいすぎたため、つるのうねりを増やし、葉柄が外へ向く角度をばらした。
2. 二稿では節の並びが規則的だったため、つるの開始位置・長さ・節の間隔を変え、葉の寸法と斜め上への傾きを変えた。最終の正面・横・真上と Blender の葉だけ・夏の花を確認した。
3. Blender で A のつるが列状に見えたため、方向にも差を付けて交差させ、つる同士を近づけ、節を増やして葉の重なりを密にした。B の砂浜へ伸びる疎な縁とは密度を分けた。

全個体の habitat は coast。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: shikoku, kyushu, okinawa。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。
