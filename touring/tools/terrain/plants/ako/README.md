# アコウ — Ficus superba var. japonica

## 制作前に決めた樹形

太く明るい幹が低い所で太枝へ分かれ、枝は横〜斜めに大きく広がる。樹冠は樹高の約 1.5〜2 倍の幅を持つ横長のドーム。裸の幹は下の約 20%、低い房も所々に下げ、樹冠の下端を平らに切らない。幹に絡む気根を網目状に組み、地面では長い根を放射状に這わせる。垂れるひげ状の気根は増やさない。

- A: 16m、幅約 28m。太枝 7 本、幹に絡む気根と長い根が発達した老木。
- B: 13m、幅約 23m。太枝 6 本、海側へやや低く広がった片寄る樹冠。
- C: 10m、幅約 17m。太枝 5 本、根とこぶの少ない若い高木。

## 共通メモへの対応

`plants/notes/ako.md` に従う。先がとがった 10〜15cm の長楕円の葉を、小枝先に長い葉柄で集める。灰白〜明るい灰褐色の滑らかな幹と、幹に絡む根を作る。岩そのものは作らず、根が地表の障害物を回り込むような起伏を付ける。幹に付く小さい実は遠目の輪郭に影響しないため省略する。

季節はメモの指定どおり 2 つ。基本は緑葉の夏・秋・冬 (14)、春は明るい黄緑〜淡いクリーム色の `_Haru` (1)。枝・根・葉板は完全に同じで PNG だけ変える。木ごとに時期がばらつく短い半落葉期を、冬の全落葉として固定しない。

紀伊半島・四国・九州の海沿い〜沖縄の集落の大木と海岸を表すため、regions=kansai, shikoku, kyushu, okinawa、habitat=farm, coast。幅の大きい木が密集しすぎないよう share=A .018、B .014、C .012。

外部の写真・画像・モデルは使わず、形・葉・樹皮は自作する。

## プレビューでの修正

1. 初稿の正面・横で樹冠の輪郭と根がそろいすぎたため、葉房の張り出しを変え、幹に絡む根のうねりと地表の根の持ち上がりに差を付けた。
2. 二稿では葉の隙間から枝が見えすぎたため、アトラスを分岐した小枝に描き直し、10〜15cm 程度の葉を保ったまま葉板の範囲を広げた。下端は房の板数を減らして高低差を付けた。最終のプレビューと Blender の緑葉・新葉を確認した。

全個体の habitat は farm, coast。配置割合と根拠は上の「共通メモへの対応」を参照。
`regions`: kansai, shikoku, kyushu, okinawa。

外部アセット・画像・モデルは使用していない。葉は 1024×1024 RGBA の 2×2 アトラスで、透明な縁へ葉色を広げた。
樹皮を使う種類では色・法線は 1024×1024 RGB、上下左右の境界画素が一致する。法線は既存の `bark.normal_map` と同じ向き。
各 GLB は画像の埋め込みがない 1 メッシュ、根元の地面中心を原点としたメートル単位の Y 上。ノード変換・骨・アニメーションはない。
葉の法線は外向き、頂点色は奥・下を暗くする。板の面も法線にそろえて書き出し、裏面は重複させていない。

## 検証と確認画像

`python plants/check.py ako` → **OK**。プレビューを見て最低 2 回改稿した後、納品 GLB と PNG を Blender 4.5.0 で読み直した。
有限値・単位法線・面の向き・樹皮の継ぎ目を追加確認済み。UE での最終的な色・光・風はマージ後に確認する。
制作スクリプト・.blend・out/ はコミットに含めず、review/ は PR 用画像のスナップショットのみを置く。
