# UE5 への取り込み手順

前提: `tools/terrain` の README の手順で `build_terrain.py` → `build_roads.py` → `apply_roads.py` → `build_scenery.py` まで実行済みであること。

## 1. 初期アセットとレベルを作る

```
"<UE5.8>\Engine\Binaries\Win64\UnrealEditor-Cmd.exe" "<リポジトリ>\FukuokaDrive.uproject" -run=pythonscript -script="<リポジトリ>\tools\ue\setup_project.py"
```

エディタを開いている場合は「ツール → Python スクリプトを実行」で `setup_project.py` を選んでも同じです。
レベル `/Game/FukuokaDrive/Maps/Futamigaura` に、二見ヶ浦の夏至の真昼 (12:00) に合わせた太陽、霧、雲、目印、PlayerStart が置かれます。

### 何度実行してもよい

`setup_project.py` は、作り方 (スクリプトのコードと定数、取り込む glTF・JSON の中身) が前回から変わったアセットだけを作り直して保存します。
何も変えずに実行し直しても、アセットにもレベルにも触らないので Git に変更は出ません。
前回の作り方のハッシュは `Content/FukuokaDrive/SetupState.json` に残るので、作り直したアセットと一緒にコミットしてください。
ログの最後の `完了 (作り直したもの: ...)` で、何を作り直したかがわかります。すべて作り直したいときは `FORCE_ALL = True` にします。

## 2. ランドスケープを取り込む (エディタで一度だけ)

1. `FukuokaDrive.uproject` を開く (Futamigaura レベルが開きます)
2. 選択モードのプルダウン → ランドスケープ → 管理 → 新規 → 「ファイルからインポート」
3. ハイトマップファイル: `tools/terrain/out/futamigaura/heightmap.png`
4. マテリアル: `/Game/FukuokaDrive/Materials/M_Landscape`
5. レイヤー欄の Road で「+」を押してレイヤー情報を作り、ファイルに `road_layer.png` を指定する。「レイヤーアルファマップのタイプ」は Additive のままでよい。Grass は何もしなくてよい (道路以外は自動で草になる)
6. `landscape_import.json` の値を入力する
   - 場所: `location_cm` (0, 0, 0)。UE5.8 の取り込み画面の「場所」はランドスケープの中心なので、角の座標を入れないこと
   - スケール: `scale` (X, Y, Z)
7. 解像度が 4033 x 4033 になっていることを確認して「インポート」
8. 保存 (Ctrl+Shift+S)

取り込んだ後に詳細パネルで見る Landscape の「位置」は北西の角なので、-201600 / -201600 / 0 になっていれば正しい (`landscape_import.json` の `corner_location_cm`)。

座標の向き: UE の +X が東、+Y が南、エリア中心が原点。海面は Z = 0。

## 糸島一周コース (Itoshima レベル)

`tools/terrain/out/itoshima_loop/tiles.json` があると、`setup_project.py` は一周コースのレベル `/Game/FukuokaDrive/Maps/Itoshima` を作ります (起動時に開くレベルもこれ)。
ランドスケープの取り込みも C++ (`UFDEditorTools::CreateLandscape`) で自動で行うので、手作業はありません。先に C++ をビルドしてください。

```
tools\ue\rebuild.bat
```

- World Partition のレベル (アクターごとのファイル) ですが、ストリーミングは切ってあり、プレイ中もすべて読み込まれています。タイルを作り直すと、そのタイルのアクターのファイルだけが変わります
- タイルごとに 4033 x 4033 のランドスケープ 1 枚 (道路は `road_layer.r8` から塗る) と、景観物・夜の光・目印を置きます。置いたものには `fd_tile_<タイル名>` の印がつきます
- 空・海・遠景・PlayerStart・ファストトラベルの行き先 (二見ヶ浦・野北・芥屋・岐志・加布里・前原・今宿・今津・西浦) は `fd_global` の印
- 開いた直後は Ocean が WaterZone に登録されず、タイルの所の海が描かれないので、`FDWaterRefresh` が読み込みから数秒おきに登録し直させて描き直させます
- 作り方が変わったタイルだけ置き直します (`SetupState.json` のキーは `.../Itoshima#landscape:<名前>`、`#tile:<名前>`、`#global`)
- 必ず GUI のエディタで実行してください (`editor.py run` か `rebuild.bat`)。コマンドライン (UnrealEditor-Cmd) で実行すると海が崩れます
- 二見ヶ浦だけの Futamigaura レベルは、`tiles.json` が無い時の手順 (下の 1〜3) のまま残っています

## 3. 確認

再生 (Alt+P) すると PlayerStart からクロスカブで始まります (W/S/A/D で走る、R で戻る)。

止まって E を押すとバイクを降りて歩けます (W/S/A/D で歩く、マウスで見回す、Shift で走る、Space でジャンプ)。
バイクはサイドスタンドで止めた所に残り、近くで E を押すと乗ります。歩いているときの R はバイクの横へ戻る、F のファストトラベルはバイクも一緒に移ります。
海には入れません (足もとが海面より 25cm 深くなる所で止まる)。木やガードレールには当たり判定がないので通り抜けます。

## 遠景の地形

ランドスケープ (4km 四方) の外側は、`build_far_terrain.py` で作った 110km 四方の 1 枚のメッシュ (Nanite、当たり判定なし) です。
玄界島・能古島・志賀島・姫島・小呂島・壱岐、可也山や背振の山並みが見え、エリアの端が崖になりません。
`setup_project.py` が `/Game/FukuokaDrive/FarTerrain` に取り込み、色は頂点カラー (`M_FarTerrain`) です。
取り込みは glTF が変わったときだけ行います (変わっていなければ取り込み済みのメッシュを置き直すだけ)。
細かさは `build_far_terrain.py` の `N_RAYS` (多いほど細かく重い)、範囲は `FAR_HALF_M` で変えられます。

## 4. 時刻の切り替え

プレイは 12:00 (`setup_project.py` の `SOLAR_TIME`) から始まります。何もしなければ時刻は止まったままで、次のキーで変えられます。画面左上に時刻と太陽の高度が出ます。

| キー | 動き |
| --- | --- |
| T (押している間) | 時間を進める (1秒で1.5時間) |
| G (押している間) | 時間を戻す |
| 1 / 2 / 3 / 4 | 朝 5:45 / 昼 12:30 / 夕方 19:12 / 夜 21:30 へ、4秒かけて進む |
| Y | 季節 (日付) を 夏至 6/21 → 秋分 9/23 → 冬至 12/21 → 春分 3/20 の順に切り替える。季節の花と桜もその季節のものになる |

太陽の位置は糸島の緯度経度と夏至の日付から計算します。夜は西の海の上に月が出て、海に月明かりが映ります。
露出・霧・ブルーム・色味は太陽の高度ごとの表から決まり、朝は日の出前後だけ霧が濃くなります (朝もや)。

### 夜

- 星空: 空の球 (`SkyDome (星空)`、マテリアル `M_FD_Sky`) に、約1万個の星 (暗い星ほど多い、色は青白から橙)、天の川 (いて座の銀河の中心ほど明るく、暗黒帯が通る)、
  東南東の福岡市と南南東の前原の街明かりを描きます。星は日付と時刻から計算した恒星時で回るので、夏至の夜なら南東の低い空に天の川の中心が見え、時間を進めると星が東から西へ動きます。
  空の球のマテリアルは大気の明るさ・太陽と月の円盤も描きます (空の球があると、大気はその上に描かれるため)
- 防犯灯: 主要道路と県道クラスの電柱の 3 本に 1 本と、交差部の近くの電柱に、道路の側へ腕を出した LED の防犯灯が付いています (`build_scenery.py` の `road_furniture.py`)。
  太陽が 1.5° より低くなると点き始め、-1.5° で全部点きます。光 (スポットライト) は `NightLights (RoadLamp)` (C++ の `FDNightLights`) がプレイ開始時に作り、
  カメラから 300m より遠いものは描きません。光る面の明るさは `setup_project.py` の `LAMP_GLOW_NITS`

調整する値は `TimeOfDay` の詳細パネルの `Night` (星・天の川・街明かりの明るさ、防犯灯が点く太陽の高度) と、
`NightLights (RoadLamp)` の詳細パネル (明るさ、色温度、届く距離、広がり、影を落とすか) にあります。
マテリアルへは `/Game/FukuokaDrive/Materials/MPC_FD_Night` で値を渡しています。

見た目の調整は、レベルの `TimeOfDay (時刻の切り替え)` を選んで詳細パネルで行います。

- `Looks`: 太陽の高度ごとの露出 (EV100、小さいほど明るい)、霧の色、太陽方向の光芒、前方散乱、ブルーム、彩度、色のかけ算
- `Time Scale`: 何もしないときの時間の流れ (0 なら止まる、60 なら1分で1時間)
- `Moon`: 月の方位・高度・明るさ
- `Morning Mist Scale`: 朝もやの濃さ

C++ を変えたので、初回はエディタを閉じて `tools\ue\build.bat` でビルドし直してから開いてください。その後 `setup_project.py` を実行し直すと、レベルに TimeOfDay が置かれます
(置かなくてもプレイ開始時に自動で置かれますが、その場合は詳細パネルで調整を保存できません)。

## 5. クロスカブの見た目

バイクの形は `tools/vehicle/build_crosscub.py` で作ります (クロスカブ110 の公称寸法に合わせた、車体・ハンドルまわり・ホイール・ライダーの4つのメッシュ)。

```
py -3 tools\vehicle\build_crosscub.py
```

その後 `setup_project.py` を実行すると (`rebuild.bat` はこの2つを続けて行う) `/Game/FukuokaDrive/Vehicle` に取り込まれ、プレイ時の `FDBikePawn` が使います
(取り込む前は仮の箱と円柱のまま)。ハンドルは切った角度だけ回り (ヘッドライトも一緒に向きが変わる)、車輪は速度に合わせて回り、
ブレーキをかけるとテールランプが明るくなります。

車体色はプレイ中に M キー (ゲームパッドはメニューボタン) で開くメニューから選べます (イエロー・ホワイト・マットグリーン・マットグレー・レッド・ブルー)。
選んだ色は `Saved/Config/<プラットフォーム>/GameUserSettings.ini` に残り、次のプレイでも使われます。

`FDBikePawn` の詳細パネルの `CrossCub|見た目` では、既定の車体色 (`Body Color Preset`、カスタムにすると `Body Color` の好きな色)、ライダーの表示 (`Show Rider`)、ブレーキランプの明るさを変えられます。
ライトのレンズの光り方は `setup_project.py` の `HEADLIGHT_LENS` / `TAIL_LENS` で変えます。

### カメラと音

V キー (ゲームパッドは右ショルダー) でカメラが「後ろ (遠く)」→「後ろ (近く)」→「ライダーの目線」と切り替わります (選んだものは次回も使われます)。
速いほど視野が広がり、カメラは車体の傾きに少しついていきます。ライダーの目線ではカーブの先を見るように向きが変わり、ライダーは隠れます。
マウス (ゲームパッドは右スティック) で視点を自由に動かせます。上を向けば走りながら夜空も見られます。
止まっているときはそのまま、10 km/h より速く走っていて 4 秒マウスを動かさないと、ゆっくり前に戻ります。ホイールクリック (右スティック押し込み) ですぐ前に戻ります。
ブレーキで前が沈み、加速で後ろが沈みます (`PitchPerG`)。調整は詳細パネルの `CrossCub|カメラ` で。

エンジン音・波の音・風切り音は音のアセットを使わず、`UFDBikeAudioComponent` (`FDBikeAudio.cpp`) がその場で合成します。
エンジンは空冷単気筒で、回転数は速度と 4 速のギア (自動で変速、遠心クラッチ) から出します。画面左上にギアと回転数が出ます。
N キー (ゲームパッドは十字キーの下) のメニューで、エンジン音・波の音・風切り音をそれぞれオン/オフできます (次回も使われます)。波の音は海の近く (まわり 30-100m に海がある所) でだけ鳴ります。
大きさは `Sound` コンポーネントの `Engine Volume` / `Wave Volume` / `Wind Volume`、ギアは `CrossCub|ギア` で変えられます。

### 自由に飛び回る

B キー (ゲームパッドは十字キーの上) で、いま見ているカメラの位置から飛び立ちます。バイクや人はその場で止まって待ち、もう一度 B で戻ります。
W/A/S/D で見ている向きへ進み、E か Space で上がり、Q か Ctrl で下がります。Shift で速く、マウスで見回し、ホイールで速さを変えます (画面左上に速さと高さが出ます)。
地面と海面より下には潜りません。木や建物は通り抜けます。時刻 (T/G、1-4) と季節 (Y) はそのまま使えます。C++ は `FDFlyPawn` です。

## 6. ミニマップとファストトラベル

画面の右下に丸いミニマップが出ます。進む向きが常に上で、縁の `N` が北です。止まっているときは半径 250m、速いほど広く (60km/h で 600m) 映します。
地図は `tools/terrain/build_minimap.py` で作った画像 (`minimap.png`) を `setup_project.py` が `/Game/FukuokaDrive/UI/T_FD_Minimap` に取り込んだものです。
画像が無いときは無地の円にバイクと行き先だけが出ます。

```
py -3 tools\terrain\build_minimap.py tools\terrain\areas\futamigaura.json
```

F キー (ゲームパッドはビューボタン) でファストトラベルのメニューが開き、選んだ場所へ止まった状態で移ります (R キーで戻る先もそこになります)。
行き先はミニマップに黄色の点で出ます。`setup_project.py` が次の場所の道路の上に、道路の向きで `FDTravelPoint` を置きます。

| 行き先 | 置き場所 |
| --- | --- |
| 二見ヶ浦 夫婦岩 | 県道54号の、夫婦岩にいちばん近い点 (開始地点と同じ) |
| 櫻井神社 | 櫻井神社にいちばん近い道路 |
| 県道54号 北東の端 (福岡市方面) | エリアの北東の端から 150m 内側 |
| 県道54号 西の端 (志摩方面) | エリアの西の端の近く |

行き先を増やすときは `setup_project.py` の `TRAVEL_POINTS` に足すか、エディタで `FDTravelPoint` をレベルに置いて `Display Name` を入れます
(高さは着いたときに地面に合わせるので、地面より上ならどこでもかまいません)。
ミニマップの大きさや映す範囲は `FDBikePawn` の詳細パネルの `CrossCub|ミニマップ` で変えられます。

## C++ のビルド

`tools\ue\rebuild.bat` を使うと、開いているエディタを保存して閉じ、ビルドし、エディタを開き直して `setup_project.py` を実行するところまで自動で行います
(`rebuild.bat nosetup` なら setup_project.py は実行しない)。
エディタの操作には `tools\ue\editor.py` (エディタの Python のリモート実行、この PC の中だけ) を使います。`Config/DefaultEngine.ini` で有効にしてあり、エディタを開き直した後から効きます。

| コマンド (`py -3 tools\ue\editor.py ...`) | 動き |
| --- | --- |
| `status` | エディタが開いていて命令を受け付けるか |
| `quit` | プレイを止め、変更をすべて保存して閉じる |
| `open` | エディタを開き、命令を受け付けるまで待つ |
| `run <スクリプト>` | 開いているエディタで Python スクリプトを実行する |

手でビルドするとき:

C++ (`Source/FukuokaDrive`) が変わったら、エディタを閉じて `tools\ue\build.bat` を実行します (`build.bat open` ならビルド後にエディタが開きます)。
エディタが開いたままだとビルドできないので、スクリプトはそのときは何もせず知らせて終わります。
エディタの再生で新しい C++ が動いているかは、画面左上の時刻の行 (`12:00   sun ...`) が出るかで見分けられます。

## Unreal MCP サーバー

エンジン付属の Unreal MCP (`ModelContextProtocol` プラグイン) を `FukuokaDrive.uproject` で有効にし、
`Config/DefaultEditorPerProjectUserSettings.ini` の `bAutoStartServer=True` でエディタを開くと自動で立ち上がるようにしてあります
(`http://127.0.0.1:8000/mcp`。手で `ModelContextProtocol.StartServer` を打つ必要はありません)。
Claude Code 用の `.mcp.json` は、エディタのコンソールで `ModelContextProtocol.GenerateClientConfig claude` を打つとプロジェクト直下に作られます。
